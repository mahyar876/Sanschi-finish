این لینک را در واتساپ بفرستید (تا لپ‌تاپ روشن و تونل باز باشد):

—

۱) GitHub — کد

Repository جدید بسازید، فایل‌های پروژه را push کنید (یا ZIP آپلود). بدون این، Render/Vercel از git نمی‌خوانند.

ساخت repo جدید GitHub Desktop

۲) MongoDB Atlas — دیتابیس رایگان

  • Cluster رایگان M0
  • Network Access → 0.0.0.0/0
  • Connection string را کپی کنید
باز کردن Atlas

۳) Render — API (backend)

  • Blueprint یا Web Service از GitHub
  • Root: backend — Start: npm start
  • Env: MONGO_URI, JWT_SECRET, بعداً BASE_URL و FRONTEND_URL
Render — Blueprint داشبورد Render

۴) Vercel — سایت (web)

  • Import از GitHub
  • Root Directory = web
  • NEXT_PUBLIC_API_URL = آدرس Render (مثلاً https://xxx.onrender.com)
  • NEXT_PUBLIC_DEMO_MODE = false
Vercel — پروژه جدید
