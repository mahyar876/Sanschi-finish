راهنمای نصب و اجرای پروژه سانس‌چی

رزرو آنلاین چمن فوتبال، سالن فوتسال و والیبال — اجرا روی ویندوز (لوکال)

این فایل برای چه کسی است؟ کسی که فایل ZIP پروژه را دریافت کرده و می‌خواهد سایت و API را روی لپ‌تاپ/PC خودش بالا بیاورد. نیاز به اینترنت برای دانلود Node.js و MongoDB و برای npm install دارید.

۱. پیش‌نیازها

نرم‌افزار نسخه پیشنهادی دانلود
Node.js (شامل npm) ۱۸ LTS یا جدیدتر nodejs.org
MongoDB Community آخرین نسخه ویندوز mongodb.com/try/download/community
ویرایشگر متن (اختیاری) — Notepad، VS Code، Cursor

۱.۱ نصب Node.js

  1. از سایت Node.js نسخه LTS را دانلود و نصب کنید (Next, Next).
  2. PowerShell یا CMD را باز کنید و بنویسید:
node -v
npm -v

باید دو عدد نسخه (مثلاً v20 و 10.x) نمایش داده شود.

۱.۲ نصب MongoDB

  1. MongoDB Community Server را برای Windows نصب کنید.
  2. در نصب، گزینه نصب به‌صورت Service را بگذارید تا با روشن شدن ویندوز اجرا شود.
  3. پورت پیش‌فرض: 27017
  4. بعد از نصب، در «Services» ویندوز سرویس MongoDB باید وضعیت Running داشته باشد.

۲. باز کردن فایل ZIP پروژه

  1. فایل reserve-football-sanschii.zip را Extract کنید (مثلاً روی Desktop).
  2. پوشهٔ اصلی معمولاً reserve-football نام دارد.
  3. داخل آن سه بخش مهم است:
پوشهکار
web/سایت (Next.js) — آدرس مرورگر localhost:3000
backend/API (Express) — پورت 5000
frontend/نسخه قدیمی HTML — برای اجرای عادی لازم نیست

۳. راه‌اندازی API (بک‌اند) — ترمینال اول

۱ PowerShell را باز کنید و بروید داخل پوشه backend:

cd مسیر\به\reserve-football\backend

مثال:

cd C:\Users\YourName\Desktop\reserve-football\backend

۲ فایل تنظیمات محیط را بسازید (فقط یک بار):

copy .env.example .env

۳ فایل .env را با Notepad باز کنید. خط مهم:

MONGO_URI=mongodb://localhost:27017/sanschii

اگر MongoDB روی همان کامپیوتر است، همین مقدار را نگه دارید.

۴ نصب کتابخانه‌ها (اولین بار؛ چند دقیقه طول می‌کشد):

npm install

۵ اجرای سرور توسعه:

npm run dev

اگر درست باشد می‌بینید:

MongoDB connected
Server running on 5000
مهم این پنجره PowerShell را باز نگه دارید. با بستن آن API خاموش می‌شود.

۴. راه‌اندازی سایت (فرانت) — ترمینال دوم

یک PowerShell جدید باز کنید (اولی را نبندید).

۱

cd مسیر\به\reserve-football\web

۲ نصب کتابخانه‌ها (اولین بار):

npm install

۳ فایل .env.local در پوشه web بسازید (Notepad):

NEXT_PUBLIC_DEMO_MODE=false

یا از نمونه کپی کنید:

copy .env.local.example .env.local

و داخلش NEXT_PUBLIC_DEMO_MODE=false را فعال کنید.

۴ اجرای سایت:

npm run dev

وقتی Ready شد، مرورگر را باز کنید:

http://localhost:3000

۵. تست اینکه همه چیز کار می‌کند

آدرسانتظار
http://localhost:3000صفحهٔ اصلی سانس‌چی
http://localhost:3000/api/healthJSON با db: true
http://localhost:5000/api/healthپاسخ سلامت API (مستقیم)

۶. ورود، ثبت‌نام و OTP

  • از منو بروید ورود / ثبت‌نام.
  • شماره موبایل ایرانی (مثلاً 09123456789) و رمز عبور وارد کنید.
  • در حالت لوکال، پیامک واقعی ارسال نمی‌شود.
  • کد OTP روی همان صفحه یا در ترمینال backend نمایش داده می‌شود — آن را وارد کنید.

۷. هر بار که می‌خواهید پروژه را اجرا کنید

  1. MongoDB باید روشن باشد (سرویس Running).
  2. ترمینال ۱: cd backend → npm run dev
  3. ترمینال ۲: cd web → npm run dev
  4. مرورگر: http://localhost:3000

۸. رفع مشکلات رایج

MongoDB connected نمی‌آید / db: false

  • Services → MongoDB → Start
  • در backend\.env مقدار MONGO_URI را چک کنید.
  • فایروال یا آنتی‌ویروس گاهی MongoDB را مسدود می‌کند — یک بار Exception بدهید.

npm install خطا می‌دهد

  • Node را به‌روز کنید (LTS).
  • اینترنت پایدار باشد.
  • دوباره: npm install

صفحه سایت باز می‌شود ولی رزرو/API کار نمی‌کند

  • backend حتماً روی 5000 در حال اجرا باشد.
  • در web\.env.local مقدار NEXT_PUBLIC_DEMO_MODE=false باشد.
  • هر دو ترمینال را یک بار ببندید و از نو npm run dev بزنید.

پورت 3000 یا 5000 اشغال است

  • برنامهٔ دیگری که همان پورت را گرفته ببندید، یا در backend\.env مقدار PORT را عوض کنید (پیشرفته).
